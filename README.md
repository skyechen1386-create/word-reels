# WordReels 6

独立的德语多角度词卡 PWA。界面来自 KnowledgeAtlas 0.7.5 的独立词卡设计，数据与离线运行采用浏览器本地架构。

## 当前版本

- 完整深色词卡与卡片内部滚动
- 到期词卡／全部词卡
- 每轮真乱序
- 德语→中文、中文→德语、常用义语境、拼读、构词、联系记忆、固定搭配、搭配例句、完整理解、造句练习、图片联想
- 各角度独立复习进度
- 1—5评分；“不会”卡片本轮稍后重现
- 间隔重复算法采用 FSRS-4.5（Free Spaced Repetition Scheduler），根据每次评分动态计算记忆稳定度与难度，目标记忆保持率 90%
- 统计页：今日复习量、连续打卡天数、总体正确率、30天趋势、各角度正确率对比、"虚假记忆"提醒
- 中→德角度：跳过输入直接看答案时会有确认提示；统计页区分"主动输入"与"直接看答案"两种正确率
- 标签筛选：复习与词库页均支持按标签（可叠加多个）筛选
- 预设模板：内置几个常用角度组合，也可将当前选择保存为自定义模板
- 造句练习角度：写完后展示该词已有例句自行对照，不强制批改，句子本身不保留
- 图片联想角度：仅在词条上传过图片时生成；只看图回忆，不给文字提示；图片存本地 IndexedDB，完全离线
- 复习交互方式可在设置中切换：按钮模式 / 手势模式（上滑翻面，左右滑动评分）
- 德语朗读：浏览器原生语音合成，可手动点击喇叭图标，也可在设置中开启翻卡自动朗读
- 我的笔记：每个词条可以写个人化的联想或记忆点，词库页和复习揭晓答案时都能编辑，自动保存
- IndexedDB 保存词库和进度
- 新版 `wordreels-word-v3` 与旧版 `wordreels-word-v1` 基础兼容
- 旧版 `wordreels-matrix-v2` 自动适配为 v3 展示结构
- 一键清空词库、各角度进度和复习记录
- 完整备份与恢复
- GitHub Pages 相对路径构建
- PWA安装与运行时离线缓存

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

`dist/` 可部署到 GitHub Pages。Vite 的 `base` 已设为 `./`，可用于仓库子路径。

## GitHub Pages

1. 将项目提交到 GitHub 仓库的 `main` 分支。
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. 项目自带的工作流会自动构建并部署 `dist/`。
4. 手机浏览器打开 Pages 地址。
5. iPhone Safari 选择“共享 → 添加到主屏幕”。

GitHub保存程序文件；词库与复习进度保存在当前设备浏览器的 IndexedDB 中。换设备前先下载完整备份。

## 数据格式

示例位于 `public/wordreels-word-v3-example.json`。核心栏目：

- 基础语法信息
- 字典直释
- 常用义排名与多义语境
- 德语解释及中文翻译
- 德语核心联想及中文翻译
- 拼读分段
- 构词拆解
- 联系辅助记忆
- 人为联想
- 固定搭配与搭配例句

程序根据实际存在的栏目自动生成学习单元，不要求每个词强制拥有全部角度。

## 清空与旧卡适配

- 如需删除一次性导入的旧词库，可先下载备份，再在“导入与备份”页点击“清空全部词卡与进度”。该操作保留设置，但会删除词条、各角度进度和复习记录。
- 导入旧版 `wordreels-matrix-v2` 时，程序会将已有信息转换到 v3 栏目。
- 旧文件中不存在的逐义语境不会被程序猜测生成，需要通过新版制卡流程补齐。
