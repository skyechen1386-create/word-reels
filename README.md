# WordReels 6

独立的德语多角度词卡 PWA。界面来自 KnowledgeAtlas 0.7.5 的独立词卡设计，数据与离线运行采用浏览器本地架构。

## 当前版本

- 完整深色词卡与卡片内部滚动
- 到期词卡／全部词卡
- 每轮真乱序
- 德语→中文、中文→德语、常用义语境、拼读、构词、联系记忆、固定搭配、搭配例句、完整理解
- 各角度独立复习进度
- 1—5评分；“不会”卡片本轮稍后重现
- IndexedDB 保存词库和进度
- 新版 `wordreels-word-v3` 与旧版 `wordreels-word-v1` 基础兼容
- 旧版 `wordreels-matrix-v2` 自动适配为 v3 展示结构
- 一键清空词库、各角度进度和复习记录
- 完整备份与恢复
- GitHub Pages 相对路径构建
- PWA安装与运行时离线缓存

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

`dist/` 可部署到 GitHub Pages。Vite 的 `base` 已设为 `./`，可用于仓库子路径。

## GitHub Pages

1. 将项目提交到 GitHub 仓库的 `main` 分支。
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. 项目自带的工作流会自动构建并部署 `dist/`。
4. 手机浏览器打开 Pages 地址。
5. iPhone Safari 选择“共享 → 添加到主屏幕”。

GitHub保存程序文件；词库与复习进度保存在当前设备浏览器的 IndexedDB 中。换设备前先下载完整备份。

## 数据格式

示例位于 `public/wordreels-word-v3-example.json`。核心栏目：

- 基础语法信息
- 字典直释
- 常用义排名与多义语境
- 德语解释及中文翻译
- 德语核心联想及中文翻译
- 拼读分段
- 构词拆解
- 联系辅助记忆
- 人为联想
- 固定搭配与搭配例句

程序根据实际存在的栏目自动生成学习单元，不要求每个词强制拥有全部角度。

## 清空与旧卡适配

- 如需删除一次性导入的旧词库，可先下载备份，再在“导入与备份”页点击“清空全部词卡与进度”。该操作保留设置，但会删除词条、各角度进度和复习记录。
- 导入旧版 `wordreels-matrix-v2` 时，程序会将已有信息转换到 v3 栏目。
- 旧文件中不存在的逐义语境不会被程序猜测生成，需要通过新版制卡流程补齐。
